Drop free / royalty-free .mp3 files here (sub-folders = categories, e.g. audio/chill/, audio/upbeat/).
Then: git add audio && git commit -m "add music" && git push  -> Vercel rebuilds audio/tracks.json and deploys.
Only add music you have the rights to (CC0, public domain, or a license that allows video use). Keep files ~1-4 MB (128 kbps) for fast mobile loading.
